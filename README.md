# Milwaukee Drive 8-Bit

The browser and phone playtest of Milwaukee Drive, playable at **https://play.andytarnoff.com**.

This repository only hosts the built game. The source, tests and the real game live in
`andytarnoff-star/milwaukeedrive` (`Tools/web_game`). The page is published from the `gh-pages` branch, and
`Tools/web_game/publish_play.sh` there updates it.
